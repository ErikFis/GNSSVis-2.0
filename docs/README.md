# Documentation

- [Offline simulation](SIMULATION.md): reproduction, outputs, model assumptions, limits, and extension points.
- [Architecture](ARCHITECTURE.md): module responsibilities and data flow.

Install the source checkout with `python -m pip install -e .` before running
examples. Downloaded ephemerides, catalogs, and observation data are excluded
from the prepared repositories. Real FITS workflows require your own data.
